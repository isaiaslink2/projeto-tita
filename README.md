# Projeto TITÃ — Criadores de IA

Programa extracurricular anual de inteligência artificial para crianças de 7 a 14 anos,
aplicado em escolas: 3 trilhas por idade, 32 aulas de 1h, culminando em cada aluno
publicando o próprio jogo.

- **Site do programa:** escopo pedagógico e comercial completo (`index.html`)
- **Demo jogável:** BATALHA DE TITÃS (`jogo/`) — jogo de luta 3D pra 2 jogadores no
  mesmo teclado, construído com as técnicas ensinadas na trilha Inventores (13–14):
  JavaScript, Three.js e IA como copiloto de programação.

Feito em Santos/SP. Modelos 3D esculpidos proceduralmente em código.
